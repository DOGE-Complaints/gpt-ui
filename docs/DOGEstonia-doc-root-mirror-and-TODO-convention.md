# DOGEstonia Docs Root Convention

## Purpose

Документ задаёт конвенции для `GPT UI/docs/` в рабочем Issue-only контуре.

## Conventions

- Рабочие документы должны использовать только Issue-терминологию и `issues/*` API-контракты.
- Устаревшие донорские формулировки не считаются нормой и не используются как operational SoT.
- Для временных зон доработки использовать метку `TODO (DOGEstonia-transform)` с конкретным шагом и owner.

## Scope notes

- `GPT UI/docs/analysis/` и task-история ведутся отдельно и не определяют runtime-поведение.
- SSOT для runtime-цепочки находится в `GPT UI/instructions/`.
