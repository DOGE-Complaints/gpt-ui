# Cognitive Systems Activated (DOGEstonia Issue)

## Scope

Документ описывает когнитивные режимы, которые должны включаться в Issue-first диалоге.

## Active cognitive systems

- **Intent routing:** корректное определение режима INGEST/SEARCH/HELP/POLICY.
- **Structured elicitation:** последовательное извлечение фактов и контекста без потери смысла.
- **Constraint tracking:** соблюдение stop-the-line и контроль готовности.
- **Policy reasoning:** проверка релевантности и admission-правил до нормализации.
- **Output discipline:** формирование контрактных артефактов для следующего шага цепочки.

## Validation rule

Каждый новый пример или сценарий в этом документе должен соответствовать текущему Issue API и требованиям `docs/requirements`.
