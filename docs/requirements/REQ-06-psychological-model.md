### 6. Психологическая модель интервью

#### 6.1. Четыре слоя пользовательского высказывания

Модуль должен быть построен исходя из того, что пользовательский ответ имеет **4 слоя**:

1. **Социально допустимый ответ**  
   «Всё нормально, просто парковок мало».

2. **Рациональный ответ**  
   «Мало мест, неудобно, нужно решить».

3. **Эмоциональный слой**  
   «Это выматывает, злит, пугает, унижает».

4. **Глубинный слой**  
   «Я хочу предсказуемости, безопасности, уважения, ощущения, что город для людей».

Инструкции должны вести пользователя **минимум до 3-го слоя** и, по возможности, до **4-го**.

#### 6.2. Что именно надо извлекать

Из интервью должны извлекаться не только факты, но и:

- глубинная потребность;
- общественная цена проблемы;
- образ желаемой среды;
- ощущение системности;
- сигнал коллективной значимости.

#### 6.3. Почему это критично

Без этого слой GPT будет генерировать обычные тикеты.  
С этим слой GPT начнёт формировать материал для кластеров, collective cases и distinct issues.
