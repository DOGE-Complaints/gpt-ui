### 15. Рабочие допущения для текущей версии

Пока не утверждены все operator-level документы, модуль 1 предлагается разрабатывать с такими допущениями:

1. Основная доменная сущность — **Issue**.
2. Интервью — строго **ingest**, без **SEARCH** как обязательного поведения в этом модуле.
3. Позитивные улучшения без явного вреда временно идут через **observation**.
4. Выход ориентирован на текущий **SPA-контракт**: type, labels, title, summary, description, опционально institution.
5. GPT не собирает **PII** по умолчанию.
6. Все финальные статусные утверждения остаются **вне GPT**.
