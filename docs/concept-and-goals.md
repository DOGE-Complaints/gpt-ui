# Concept and Goals (DOGEstonia Issue)

## Product focus

DOGEstonia GPT UI поддерживает civic intake по модели Issue: пользовательский рассказ → структурированный пакет → проверка политики и безопасности → передача в API.

## Core goals

- Собирать релевантные civic-сигналы в понятном диалоге.
- Сохранять строгую цепочку модулей без обходов и скрытых переходов.
- Поддерживать единый контракт данных между GPT, нодой и SPA.
- Обеспечивать прозрачные причины `approved` / `needs_clarification` / `rejected`.

## Non-goals

- Нет произвольного изменения backend-статусов без API-ответа.
- Нет смешения ingest-логики с search/read-only операциями.
- Нет хранения лишних персональных данных.
